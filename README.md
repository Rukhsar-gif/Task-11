# Recipe Card Page

A responsive recipe card page created as **Task 11** of my
**Web Development Internship at Veda Technology**.

## 📌 Project Overview

This project is a single recipe card page that presents a recipe
image, ingredients list, preparation steps, and a cooking tip in a
clean and responsive layout.

The project focuses on semantic HTML structure and CSS card styling.

## 🎯 Objective

The objective of this task was to practice:

- Semantic HTML5
- Unordered lists
- Ordered lists
- Figure and figcaption
- CSS card styling
- Spacing and typography
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Recipe image
- Image caption
- Ingredients list
- Numbered preparation steps
- Recipe information
- Cooking tip
- Responsive design
- Semantic HTML structure
- Clean card-based layout

## 🍝 Recipe

### Creamy Garlic Pasta

A simple pasta recipe made with creamy garlic sauce, Parmesan
cheese, and fresh herbs.

### Recipe Information

- Preparation Time: 25 minutes
- Difficulty: Easy
- Servings: 2
